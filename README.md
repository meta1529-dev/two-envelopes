# ふたつの封筒

公開URL: https://meta1529-dev.github.io/two-envelopes/

2つの封筒に違う金額が入っていて、片方だけを開けて「そのまま持つ」か「交換する」かを決めるゲームのシミュレーションです。

## 戦略

適当に思いついた数字 T と、開けた封筒の金額を比べます。

- 開けた額 > T なら、そのまま持つ
- 開けた額 < T なら、交換する

T が「安い方 < T < 高い方」に入る確率を P とすると、

勝率 = (1 − P)・½ + P・1 = ½ + P/2

となり、P > 0 なら必ず 1/2 を超えます。

## ページの内容

- **やってみる**: 封筒を開けて、T を思いつき、持つか交換するかを選ぶ対話型ゲーム
- **なぜ勝てるのか**: T の位置による3通りの場合分けと式
- **大量に試す**: 「いつも持つ」「いつも交換」「しきい値戦略」を何千回も試して勝率の推移をグラフ表示。封筒の金額の分布と T の選び方を変えられます

依存ライブラリなしの `index.html` 1ファイルです。ブラウザで開くだけで動きます。
